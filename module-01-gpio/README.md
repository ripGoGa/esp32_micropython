# Модуль 1. GPIO

## Задания
1. `task1_button_state`: печатать сообщение только при изменении состояния кнопки.
2. `task2_toggle_led`: кнопка переключает светодиод, с защитой от дребезга по времени.

## Схема
- Кнопка: GPIO 4 и GND, напрямую, с `Pin.PULL_UP`.
- Светодиод: GPIO 5, резистор 220 Ом, анод; катод на GND.

## Что узнал
- Со `PULL_UP` отпущенная кнопка читается как 1, нажатая как 0.
- Светодиод нельзя ставить последовательно с кнопкой: он искажает уровень на пине, и значение не меняется.
- Нужно реагировать на событие нажатия (переход 1 → 0), а не на состояние.
- Дребезг контактов даёт несколько срабатываний за одно нажатие. Решение: опрос с интервалом через `ticks_ms()` и `ticks_diff()`.
- `prev_state` обновляется после сравнения, на каждой проверке.
- Для выхода (светодиода) режим `Pin.OUT`, подтяжка не нужна.
