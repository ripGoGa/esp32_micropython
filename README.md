# ESP32 MicroPython: учебный репозиторий

Прогресс обучения программированию ESP32 на MicroPython.
Инструменты: MicroPython, `mpremote`, Wokwi, VS Code.
Итоговый проект: система определения ключа в двери.

## Прогресс

- [x] Модуль 0. Подготовка
- [ ] Модуль 1. GPIO
  - [x] Задание 1. Состояние кнопки
  - [x] Задание 2. Кнопка-переключатель со светодиодом
  - [ ] Задание 3. Два светодиода поочерёдно
- [ ] Модуль 2. Прерывания и таймеры
- [ ] Модуль 3. ADC и ШИМ
- [ ] Модуль 4. I2C, SPI, UART
- [ ] Модуль 5. Асинхронность
- [ ] Модуль 6. Wi-Fi и сеть
- [ ] Модуль 7. Энергосбережение и надёжность
- [ ] Финальный проект: ключ в двери

## Как запускать

На плате:

```bash
mpremote run module-01-gpio/task2_toggle_led/main.py
```

В симуляторе: открыть шаблон MicroPython на wokwi.com, вставить `main.py` и `diagram.json`.
